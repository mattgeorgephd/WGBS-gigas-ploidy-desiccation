# 04_output

Results written by the pipeline. Nothing here is edited by hand; every file is regenerated by the script named in its folder.

## Layout

```text
04_output/
  <step>/                 one folder per script in 01_pipeline/, named after the script, for example 05_differential_methylation/
    tables/               CSV (gzipped when large)
    figures/              PNG and PDF panels
    session_info.txt      R and package versions of the run that wrote the folder
```

## What is tracked

Files up to 50 MB are committed, so every later step, and every reader of the manuscript, can start from the repository alone. That includes the united 10x methylation table from step 05 (gzipped), which is the input to all downstream steps.

Larger intermediates (per-library filtered objects, model fits) are written under `04_output/<step>/cache/`, which is git-ignored, and are rebuilt by rerunning the step.

## File naming

Outputs that depend on an analysis mode carry the mode in the file name, for example `dml_ploidy_legacy.csv` and `dml_ploidy_corrected.csv`. The modes are defined in `run_config.R` and described in `07_documentation/reproducibility_plan.md`, section 4.
