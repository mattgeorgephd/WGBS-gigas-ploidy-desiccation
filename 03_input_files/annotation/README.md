## Things to know

- The GO terms in the maps came from a 2017 UniProt-to-GO table (`uniprot-SP-GO.sorted`) on a server that no longer responds; no copy of that table has been found in the project locations. The maps are therefore the frozen annotation source: GO terms as UniProt held them in July 2017, attached to blastx hits of June 2021. See issues I-33 and I-42 in [`issues.md`](../../issues.md).
- The maps are keyed by transcript, one line per blastx alignment, so a transcript appears on as many lines as its best hit has aligned segments; all lines of a transcript are identical. The legacy analysis treated each transcript as a gene; see issue I-03.
- In the legacy maps, transcript IDs were rebuilt with an `XM_` prefix regardless of their true prefix. Of the 45,346 names with GO terms, 43,184 are `XM_` mRNAs, 123 are curated `NM_` mRNAs written as `XM_` (and therefore lost in the legacy analysis), and 2,038 are non-coding `XR_` transcripts written as `XM_`; the one remaining name is the bare prefix `XM_`, left by tRNA queries whose ID holds no transcript accession. The pipeline recovers the true IDs from the blastx query IDs (`true_transcript_ids()` in `02_R_functions/annotation.R`) and uses the mRNAs only.
- The files in `legacy/` are outputs of the legacy analysis, not inputs of the corrected one. They are kept here, under the GitHub-first rule, because the checks need them and because the lost GOslim table can only be recovered from them. The files in `legacy/revigo_exports/` and `legacy/fisher_other_analysis/` are here for step 11 (`01_pipeline/11_semantic_similarity.R`), so that no step reads `08_archive/`; the originals stay in the archive.
- Transcript-to-gene and transcript-to-product relations are read from `../genome_features/cgigas_uk_roslin_v1_mRNA.gff.gz`.
