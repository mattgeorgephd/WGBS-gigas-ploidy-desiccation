# 05_manuscript

The manuscript's figures, table and supplementary lists under the numbers the manuscript uses, and the table that ties each number quoted in the manuscript to the pipeline output that regenerates it. Everything here is written by `01_pipeline/13_manuscript_values.R` from the outputs in `04_output/`; nothing is drawn, typed or edited by hand. Rerun step 13 after any step that changes an output.

Everything here outside `not_adopted/` is the paper's: the paper run (`Rscript run_pipeline.R`) writes it and nothing else. `not_adopted/` holds the values, figures and lists of the optional analyses, which the paper did not adopt; step 13 writes it in an optional run (a run with any switch of `run_pipeline.R`).

## Reading `manuscript_values.csv`

- `status` is `matches` when the regenerated value equals the manuscript value within the tolerance of the row, `differs` when it does not, and `not regenerated` when the statement is about something the pipeline does not compute (a laboratory detail, a design statement, a software version); the note says why.
- A row can match and still be wrong science. "Matches" means the pipeline reproduces the number, not that the number means what the text says. The `issue` column points to the entry of `issues.md` that covers it, and `not_adopted/manuscript_values_by_analysis.csv` gives the value of each statement in the optional analyses. None of them is the analysis that `issues.md` supports for the DML themselves (I-06) or for their location (I-41).
- State on 2026-11-20: 545 statements (Methods, Results 3.1 to 3.5, Table 1, figure legends, Discussion and Conclusions). 352 match, 146 differ, and 47 cannot be regenerated by a pipeline (laboratory and design details); with the coverage filter of the Methods (analysis `corrected`, in `not_adopted/manuscript_values_by_analysis.csv`), the paper's own computation gives a value that does not agree with the draft for 210 of 498 statements (161 of 263 with the corrected recipe). Counts by section are in `manuscript_values_summary.csv`. The statements that differ are concentrated in Results 3.4 (34 of 44) and the Discussion (60 of 115): most are statements that a function is enriched, that a difference exists at baseline, or that a response to heat differs by ploidy (issues I-41, I-48, I-02, I-03, I-01, I-07).

## Reading `not_adopted/manuscript_values_by_analysis.csv`

Each row is one statement in one optional analysis, with two values (decision of the author, 2026-11-20; `07_documentation/reproducibility_plan.md`, section 7, "Decided").

- **Paper recipe** (`regenerated`, `differs_from_manuscript`, `status`): the paper's own computation, `expression_legacy`, applied to the tables of the analysis (column `expression_paper_recipe` of the values map, generated from `expression_legacy` by `07_documentation/toggles_migration/paper_recipe_column.py`). A difference from the paper's value in `manuscript_values.csv` therefore comes only from the option. Applied to the paper's own outputs (`A = "legacy"`) every one of the 498 templates gives the paper's value exactly (`tests/check_paper_recipe_legacy.R`). Four kinds of row needed more than a change of file name (the script lists them): the Table 1 group means of `06_diagnostics/table1_group_means.csv` are recomputed for the Table 1 of the analysis (13 rows); the GO terms named in Results 3.4 are looked up in the analysis's own Fisher tables of step 09 (24 rows, plus D4.3-006 and D4.8-003, which count its terms with p below the cutoff); the rows that read the per-CpG table of step 05 read its rows at the DML, `united_at_dml_<id>.csv`; and D4.9-014 gives NA when the two AK9 loci are not both among the analysis's loci in both lists. Six rows read a table that only the paper run makes (the "as drawn" clusters of Figures 6 to 8 and the REVIGO exports of step 11: R3.4-007, R3.4-008, R3.4-009, R3.4-013, R3.4-024, R3.4-035) and are `not run` in every optional analysis. A statement about a locus, gene or Table 1 row that the analysis does not have is `not comparable: no value in this analysis`, or `not comparable` where the expression gives NA.
- **Corrected recipe** (`regenerated_corrected_recipe`, `differs_from_manuscript_corrected_recipe`, `status_corrected_recipe`): the template of `expression_optional`, the expression of the former column `expression_corrected` (the corrected mode of the audit) with the analysis id `A` in place of `corrected`. For most rows that is the paper's own computation; for some it is a corrected definition of the quantity or another column (for example R3.1-001 counts the CpGs with a read with every line read and no upper filter where the analysis uses the coverage filter of the Methods; shares of CpGs instead of shares of overlaps; deduplicated counts for the analyses of variance). Applied to the paper's own outputs these templates give a value other than the paper's in 56 of 263 rows (2026-11-20), so a difference between a corrected-recipe value and the paper's value is not only the effect of the option. Rows R3.1-001 and R3.1-003 take the column of the analysis's coverage filter (`cpg_in_any_library` in the legacy reading, `cpg_in_any_library_unfiltered` with option `corrected`). These values are those the file held before 2026-11-20 in `regenerated`, `differs_from_manuscript` and `status`, unchanged.
